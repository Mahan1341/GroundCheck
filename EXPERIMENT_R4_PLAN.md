# R4 preregistration — inference only, 2026-10-24

Freeze this file and generated suites before any R4 inference. No training,
new threshold, outer calibration/dev/test, or old-artifact overwrite.

Models: B7 inner seed42, R2 CE seed42, R3-A seed42. These isolate the natural
baseline, relation training and representation-augmented training. All use the
historical response threshold 0.37612172961235046 (>= positive) and token .5.
Do not run full-train checkpoints on inner-validation. Pin weight hashes in runner.

Datasets: unchanged R3 diagnostic640/12 parents; fresh fictional R4 worlds
generated by numeric_local_suite.py (12 independent names, 4 per measurement
kind, new values/rendering), and unchanged natural inner-validation648/108.
Source/parent disjointness from all supervised train inputs is verified.
New suite crosses supported/contradicted values and evidence order, with same
answer for each pair and both competing values present in evidence. Fresh
conditions: digits, evidence words, answer words, both words, equivalent units
on both sides, long answer with 12/36 true sentences (middle error), long-distance
coreference (full fallback), and a short erroneous clause inside one long sentence.
Controlled worlds are authored, not extracted RAGTruth; no retrieval gold claim.
Ranges/approximations are tested offline as unchanged inputs, not fabricated gold.

A: raw, evidence-only R4 normalizer, symmetric R4 normalizer. Same conservative
normalizer in both arms; historical R3 normalizer retained unchanged. Canonical
digits and integer exact minutes/meters, typed bolt counts; unsupported arithmetic,
decimals, ambiguous/coordinated/range/approximate clauses unchanged. Map all
rewritten chars to original numeral/unit intervals. Use common original tokenizer
grid, max overlap for projected probabilities; report projection breadth as a
limitation, not subword alignment truth. Response score remains native max.

B: raw full answer versus every extractive sentence + immediate neighbors,
unchanged full question/evidence. Central sentence alone contributes scores;
project onto common original token grid, max overlap, then max-token response.
Any explicit anaphora triggers full-answer fallback to retain antecedents.
No oracle claim selection. This is a bounded heuristic, not guaranteed coreference
resolution. No normalization/local combined arm in this packet.

Primary: within-model deltas vs raw, separately per dataset; macro-F1, supported
FPR, contradiction recall (exclude unsupported R3 from this denominator), paired
correct classification, fixed-.5 token/character/exact-span F1. Same original
offset grid. Pair means clustered by parent, no treating variants as independent.
2000 paired parent/source bootstrap draws seed42, absolute and difference intervals;
also R3 name-group sensitivity because names repeat across measurement kinds.
Natural short-error subset: response>=500 chars and annotated coverage<=5%,
response recall AND gold-token hit at .5; length bins original-token <=64,65-128,>128.
Record transformed tokens, changes, all offsets, view counts, fallback and full
evidence/answer coverage, runtime and peak VRAM. No silent context truncation.

Budget: serial inference only, max30 GPU minutes initially; stop and document
resource failure rather than truncate. Existing full context limit2048, batch2.
No diagnostic-driven threshold/implementation changes after viewing results.
Implementation correctness fixes require immutable before/after artifacts and reason.

Hypotheses: A reduces representation false alarms while retaining entity binding;
B restores short-error sensitivity by reducing answer distraction without omitting
claims. A genuine gain requires pair/contradiction and localization retention,
not merely lower risk for every input. Natural transfer reported separately.
Only after results propose one matched training experiment with explicit loss,
data, gate and resource budget. No launch in R4.

During implementation review, before inspecting any R4 metric, the blanket `to`
guard was found to reject the fresh suite's ordinary `According to` prose. The
initial B7 inference was stopped during old/local after raw/evidence/symmetric
outputs; no fresh inference had completed. Entire initial freeze, predictions,
logs, reports and original normalizer are preserved under
models/phase2b_r4/parser_pilot, with the original content-addressed source ZIP.
Replace blanket `to` rejection by number-to-number / number-through-number range
rejection and add regression tests. No labels, thresholds, examples or other
method choices change. Re-freeze and rerun the full packet under corrected code.
This is a correctness repair, not selection between observed model metrics.
